# Rozwiązania zadań – Python

Każde zadanie programistyczne znajduje się w osobnym pliku `.py`.

## Foldery
- `01_listy_podstawowe` – zadania 1–13 z pierwszej części.
- `02_tablice_dwuwymiarowe` – zadania 2–6 z części o tablicach dwuwymiarowych.
- `03_praktyka_czyni_mistrza` – zadania programistyczne 2–38 z części „Praktyka czyni mistrza”.

## Jak uruchomić
1. Rozpakuj archiwum.
2. Otwórz folder w Visual Studio Code.
3. Otwórz wybrany plik `.py`.
4. Uruchom go przyciskiem Run Python File albo poleceniem `python nazwa_pliku.py`.

## Ważne
- Zadania polegające wyłącznie na obejrzeniu filmu lub przeczytaniu rozdziału nie są programami, dlatego nie mają osobnych plików z kodem.
- Zadania korzystające z `matplotlib` wymagają instalacji biblioteki: `pip install matplotlib`.
- W zadaniu z modułem `MyArrays.py` uruchamiaj plik główny i trzymaj `MyArrays.py` w tym samym folderze.
- W zadaniu z modułem `MyText.py` uruchamiaj plik główny i trzymaj `MyText.py` w tym samym folderze.
- Każdy program ma komentarz na początku z oznaczeniem „4, Zadanie …”.

## Dodatkowe opisy
Na początku każdego pliku znajduje się krótkie polecenie zadania.
Funkcje mają krótkie opisy zapisane w docstringach, bezpośrednio pod ich definicjami.
