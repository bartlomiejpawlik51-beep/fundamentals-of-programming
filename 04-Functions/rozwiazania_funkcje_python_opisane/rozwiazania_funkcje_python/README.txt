# Rozwiązania zadań – funkcje i moduły Python

Każde zadanie programistyczne jest w osobnym pliku `.py`. Na początku pliku znajduje się:
- podpis `4, Zadanie ...`,
- krótkie polecenie zadania,
- komentarze/opisy funkcji bezpośrednio pod definicjami.

## Foldery
- `01_funkcje_wbudowane` – zadania z funkcji wbudowanych.
- `02_funkcje_i_moduly` – zadania z modułów, funkcji i turtle.
- `03_praktyka_czyni_mistrza` – zadania praktyczne.

## Uruchamianie w Visual Studio Code
1. Rozpakuj archiwum.
2. Skopiuj foldery do wybranego podfolderu projektu.
3. Otwórz plik `.py` i uruchom go przyciskiem Run Python File.

## Ważne informacje
- Pliki korzystające z własnych modułów muszą znajdować się w tym samym folderze co odpowiedni moduł:
  - `zadanie_9_test_converters.py` i `converters.py`
  - `zadanie_10_employee.py` i `keyboard.py`
  - pliki z rysowaniem oraz `figures.py` / `figures_all.py`
  - `zadanie_1_month.py` i `months.py`
  - `zadanie_2_letter_counter.py` i `letter_counter.py`
  - `zadanie_3_number_range.py` i `number_range.py`
  - `zadanie_4_hide_card.py` i `card_tools.py`
- Zadania z `turtle` otwierają osobne okno z rysunkiem.
- W zadaniu z oceną przyjęto progi dokładnie według treści: 0–9 niedostateczny, 10–13 dostateczny, 14–17 dobry, 18 i więcej doskonały.
- Zadania polegające wyłącznie na obejrzeniu filmu, przeczytaniu rozdziału lub zapoznaniu się z opisem nie są osobnymi programami.
- W zadaniu z alfabetem ICAO słowa literowania są wpisane w słownik w programie, ponieważ plik icao.py nie był dołączony do materiałów.
