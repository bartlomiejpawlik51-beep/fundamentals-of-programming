JAK URUCHAMIAC:
1. Rozpakuj archiwum.
2. Otworz rozpakowany folder w VS Code.
3. Uruchamiaj pojedynczy plik .py, np. 01_wyswietl_kraje_ponumerowane.py.
4. Nie zmieniaj nazw plikow z danymi – programy korzystaja z nich bezposrednio.
